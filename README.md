# Parser Otchetov

Внутренний инструмент HR-отдела для анализа данных сотрудников.
Читает CSV-файл и формирует сводные отчёты по отделам.

## Установка
python parser.py

## Формат входного файла
Файл sotrudniki.csv должен содержать колонки:

имя, отдел, должность, зарплата, дата_приема

## Пример данных
Иванов Иван, IT, Разработчик, 120000, 2023-03-15
Петрова Анна, HR, Менеджер, 85000, 2022-07-01

## Возможности
- Сводка по отделам (количество, средняя зарплата, стаж)
- Список сотрудников конкретного отдела
- Топ сотрудников по зарплате
- Валидация входных данных

## Структура проекта
parser.py — основной модуль
sotrudniki.csv — входной файл с данными
